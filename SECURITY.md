# Security policy

Do not open a public issue for a suspected vulnerability. Use **Security → Report a vulnerability** in the Scenelith GitHub repository to open a private security advisory. Include affected versions, impact, reproduction steps, and any proposed mitigation. Do not include real user data, provider credentials, or production secrets.

Security fixes are supported on the latest released version. Self-hosted operators are responsible for applying updates, protecting provider credentials, restricting host access, configuring HTTPS, monitoring storage capacity, and maintaining tested backups.

Scenelith never needs Cloud commerce credentials in the self-hosted distribution. Treat any installation guide requesting those credentials as untrusted.
