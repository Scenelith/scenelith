# FLUX 3 Klein and Canvas defaults

Verified against KIE on 2026-10-22:

- [Model and pricing](https://kie.ai/flux-3)
- [Text to image](https://docs.kie.ai/market/flux3/klein-text-to-image)
- [Edit](https://docs.kie.ai/45558886e0)
- [Wan 3](https://docs.kie.ai/market/wan/3-0-video)

The portable model ID `flux-3-klein` dispatches to
`flux-3/klein-text-to-image` without references and
`flux-3/klein-edit-image` with references, through the existing Market task,
callback and output-import pipeline. Image Edit always puts `@EditSource`
first. Its reference map uses the provider's `image 1`, `image 2` names.

Supported inputs: prompt up to 5,000 characters; 1–10 JPEG/PNG/WebP references
up to 30 MB each; 1K, 2K, 4K; nine fixed aspect ratios, plus `auto` only with
references. PNG is the default; API callers may set `outputFormat` to `jpeg`
or `webp`, `seed` to an integer 0–2147483647, and `enhancePrompt` explicitly.
Enhancement defaults to true for text generation and false with references
so editing instructions stay literal. The Canvas batch control keeps one
image per independently tracked task (`num_images: 1`), with its existing
per-node accounting; it does not combine tasks into an untracked provider
batch. Custom provider width/height are not exposed by the Canvas.

KIE rates per image are 1.6/2.5/6.5 provider credits at 1K/2K/4K, equally for
generation and editing. References add no cost. The shared quote table rounds
to whole quote units (2/3/7); the edition usage authority remains responsible
for billing policy and reservation/refund settlement.

New Canvas and MCP generator nodes use Nano Banana 2.1 (images) or Wan 3
(videos), with 9:16 when supported. Saved model and ratio selections remain
unchanged. With a video input, Wan's duration selector defaults to
`From reference`; users may still choose fixed output seconds. Like Reviral,
the generated duration rounds up to whole supported seconds, minimum 2.
A single source above 15 seconds uses a cached first-15-second derivative
through the shared media pipeline; original media and selected scenes remain
intact. Multiple videos retain their order and the existing 15-second total
budget, rather than silently dropping inputs. Quotes use the prepared video
duration plus the resolved output duration. MCP exposes `duration_mode` with
`reference` and `fixed` values; explicitly configuring seconds selects fixed
mode unless a mode is also provided.
